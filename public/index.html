System Data Model & Schemas

Visual representation of JSON schemas mapping Question, Test, Attempt, Answer, and Result models.

1. Question Model Schema

{
  "id": "Q101",
  "text": "Question Text string...",
  "image": "https://url.com/img.jpg" (Optional),
  "category": "Arithmetic",
  "subCategory": "Profit & Loss",
  "difficulty": "Easy" | "Medium" | "Hard",
  "type": "MCQ" | "Multiple Correct" | "True/False",
  "options": [ // Array of option records (min 4, max 5)
    { "id": 1, "text": "Option Text A" },
    { "id": 2, "text": "Option Text B" },
    ...
  ],
  "correctAnswer": [2], // Option IDs mapped as array
  "explanation": "Detailed explanation...",
  "marks": 3,
  "negativeMarks": 1.0,
  "language": "English",
  "status": "Active",
  "createdAt": "ISOString",
  "updatedAt": "ISOString"
}
